# Cara ganti gambar

1. Buka folder ini di GitHub.
2. Klik "Add file" > "Upload files".
3. Upload gambar kamu, kasih nama file **hero.png** (harus sama persis, huruf kecil semua).
4. Kalau ada gambar lama namanya hero.png, akan otomatis ke-replace/ketimpa.
5. Commit langsung ke branch main.
6. Tunggu ~30 detik - 1 menit, refresh halaman live-nya.

Kalau nggak upload gambar sama sekali, halaman tetap tampil pakai ilustrasi ikan bawaan (fallback), jadi nggak akan pernah kelihatan rusak/kosong.
